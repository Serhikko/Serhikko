## 📱 Slovira — learn any pair of 33 languages

My main project: a language-learning app I designed, built and shipped **solo, to four stores in ~4 months** — from a single codebase. (Source is private while the product is commercial — happy to walk through the code in an interview.)

[**App Store**](https://apps.apple.com/app/id6779954616) · [**Google Play**](https://play.google.com/store/apps/details?id=com.slovira.app) · [**Microsoft Store**](https://apps.microsoft.com/detail/9P23HG4KC5BT) · [**slovira.app**](https://slovira.app)

- **Stack:** Flutter/Dart + Firebase (Auth, Firestore, Cloud Functions, FCM) · offline-first with Hive + cloud sync
- **Surfaces:** iOS · Android · Windows · Chrome & Firefox extensions — all sharing one Firestore backend
- **Features:** SM-2 spaced repetition · AI chat tutor (zero-key Gemini proxy via Cloud Functions with per-user quotas) · built-in reader with 140+ graded books in 17 languages · XP, levels & leaderboards · TTS
- **Operations:** App Store / Google Play / Microsoft Store review cycles, staged releases, versioned data migrations · localized into 30 languages · GDPR-conscious data handling with in-app account deletion
